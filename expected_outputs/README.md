# Expected Outputs

After running:

```powershell
.\run_infer_quick_demo.ps1
```

the following files should be created:

```text
outputs/quick_demo_predictions/pred_mp4/
outputs/quick_demo_predictions/gifs/
outputs/quick_demo_predictions/samples_metadata.jsonl
outputs/quick_demo_predictions/samples_summary.json
```

If the checkpoint is provided, these outputs allow reviewers to verify that the inference pipeline is functioning.
